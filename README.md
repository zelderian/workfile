# Робота з файлами — C++ (багатофайлові проєкти)

## Завдання 1 (Task1)
Student.h / Student.cpp - структура Student та функції запису/читання файлу,
виводу студентів нижче заданого балу, обчислення середнього балу.
main.cpp - точка входу.

Компіляція:
    g++ -std=c++17 -o task1 Task1/main.cpp Task1/Student.cpp

Запуск:
    ./task1

## Завдання 2 (Task2)
TextFilter.h / TextFilter.cpp - завантаження списку заборонених слів,
читання/запис файлу, фільтрація тексту від заборонених слів.
main.cpp - точка входу, створює приклад вихідного файлу та списку заборонених слів.

Компіляція:
    g++ -std=c++17 -o task2 Task2/main.cpp Task2/TextFilter.cpp

Запуск:
    ./task2

## Завдання 3 (Task3)
Transliterator.h / Transliterator.cpp - таблиця транслітерації (українська національна система),
читання/запис файлу, функція transliterate().
main.cpp - точка входу, створює приклад українського тексту та транслітерує його.

Компіляція:
    g++ -std=c++17 -o task3 Task3/main.cpp Task3/Transliterator.cpp

Запуск:
    ./task3
